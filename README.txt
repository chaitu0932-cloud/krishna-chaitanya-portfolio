KRISHNA CHAITANYA — STUDENT PORTFOLIO

FILES
- index.html : website content and sections
- style.css  : colors, layout, responsive styling and animations
- script.js  : mobile navigation and dynamic copyright year

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser.
4. Optional: install the Live Server extension in VS Code and click "Go Live".

CUSTOMIZE
- Update your text and links in index.html.
- Change colors and styling in style.css.
- Add your own photo by replacing the KC initials profile circle with an image.
- Check all project and social links before submitting.

This website uses HTML, CSS and JavaScript only. No package installation is needed.
